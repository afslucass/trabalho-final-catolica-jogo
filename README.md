# Setup

1. Instale o .Net: https://docs.monogame.net/articles/getting_started/1_setting_up_your_os_for_development_windows.html?tabs=android
2. Abra o terminal e rode o seguinte comando: dotnet new install MonoGame.Templates.CSharp
2. No VSCode, instale as seguintes esxtencoes: "C# Dev Kit" e "MonoGame for VSCode"
